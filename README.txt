MindMate AI — No-Python Version

HOW TO RUN
1. Extract this ZIP file.
2. Open the extracted folder in VS Code.
3. Open index.html and double-click it, or right-click and choose Open with Live Server (if installed).
4. Use the website in Chrome or Edge. No Python or pip installation is needed.

FILES
- index.html: page content
- style.css: design and responsive layout
- script.js: check-in, demo reflections, chart, chat demo, and download button

LIMITATIONS
This is a browser-only student project prototype. It does not use Python, Flask, a real machine-learning model, or a live AI service. Check-in reflections use simple demo rules and are not medical diagnoses. Data stays in the current page session unless you download a JSON reflection file.
